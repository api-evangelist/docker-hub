# Docker Hub

Docker Hub is the world's largest container image registry, providing a cloud-based service for finding, storing, sharing, and managing container images. It offers public and private repositories, automated builds, webhooks, and integrations with Docker tooling and CI/CD pipelines.

**Website:** [https://hub.docker.com/](https://hub.docker.com/)

## APIs

| Name | Description |
|------|-------------|
| [Docker Hub API](https://docs.docker.com/docker-hub/api/latest/) | Programmatic access to repositories, images, tags, organizations, teams, webhooks, and access tokens. |

**OpenAPI:** [openapi/docker-hub-openapi.yml](openapi/docker-hub-openapi.yml) (OpenAPI 3.0.3, version 2-beta, `https://hub.docker.com/v2`)
